
1. বাজার দর | BazarDor

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর সহজে দেখা ও তুলনা করার জন্য তৈরি একটি আধুনিক ওয়েব অ্যাপ্লিকেশন।

2. About the Project

বাজার দর ব্যবহারকারীদের চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার মতো নিত্যপ্রয়োজনীয় পণ্যের দাম সম্পর্কে জানতে সাহায্য করে। ব্যবহারকারীরা পণ্যের দাম দেখতে, তুলনা করতে এবং নিজের অ্যাকাউন্ট পরিচালনা করতে পারেন।

3. Technologies Used

i. Next.js — React-based web framework
ii. Next.js App Router — Page routing and navigation
iii. React — Interactive user interfaces
iv. JavaScript— Application logic
v. Tailwind CSS — Responsive styling
vi. daisyUI — UI components
vii. Better Auth — Authentication and user account management
viii. MongoDB — Database
ix. Vercel — Deployment

4.  Key Features

i. **Product Price Tracking** — View prices of essential grocery products.
ii. **Product Categories** — Browse products by category.
iii. **Price Sorting** — Sort products from low to high or high to low, with support for Bengali numerals.
iv. **Secure Authentication** — Sign up and sign in using Better Auth.
v. **Profile Management** — View profile information and update your name.
